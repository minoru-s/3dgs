# 3DGSビューアーの表示比較

PLYを開き、右の「表示比較」で同じ視点のまま切り替えます。

- 従来表示: SH 0、アンチエイリアス無効、除外しきい値5、kernel 0.30。
- 今回向け（初期設定）: SH 2、アンチエイリアス有効、除外しきい値5、kernel 0.30。
- 薄い点を減らす: 今回向けから除外しきい値だけを16に変更。

プリセットは押すと適用されます。個別調整は「表示に適用」を押します。再読み込み中はプリセットと適用ボタンを無効にし、カメラ位置・向き・注視点を保って描画し直します。

## 限界

表示設定はPLYを変更しません。低い不透明度の点の除外は浮いた点だけを識別する処理ではなく、正常な細部も消す場合があります。形状の崩れや未撮影の面を復元する機能ではありません。

GaussianSplats3D 0.4.7のSH描画は次数2までです。SH次数3の公式レンダラーと完全に一致するものではなく、画像ごとの学習済み露出補正も適用していません。アンチエイリアス無効で学習した別モデルには、個別設定でチェックを外してください。

## 視点保存

「この視点を保存」は `3dgs-view.json` をダウンロードします。Three.jsのカメラ位置、姿勢、注視点、投影行列、表示設定を含み、公式レンダラーで同じ視点を照合するために使えます。モデルや入力画像は含まれません。ローカル選択時はモデルのファイル名が含まれます。ファイル選択で開いたモデルをサーバーへアップロードする処理はありません。

## 確認（2026-09-23）

106MB・427,133点の実モデルをMacのChromeで読み込み、3プリセットを切り替えて表示を確認。従来表示と今回向けで保存したカメラ位置・姿勢・注視点・投影行列が一致。切り替え後もcanvasは1枚で、コンソールエラー・警告なし。形状の大きな崩れは表示設定だけでは解消しませんでした。

ブラウザ自動操作のローカルファイル選択は拡張のファイルアクセス設定で未検証です。実モデルはループバックのHTTP経由で読み込みました。
